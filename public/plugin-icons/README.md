# Plugin catalog marks

SVG marks in this directory are from Simple Icons, retrieved 2026-10-20:
https://github.com/simple-icons/simple-icons/tree/develop/icons

The original path data is preserved, with a local fill color added. Simple Icons artwork is CC0-1.0; see LICENSE.md. Brand names and marks remain the property of their owners. Local fallback symbols/initials are rendered in PluginIcon.tsx when a mark is unavailable. No remote icon service is contacted at runtime.
