# SuperGPT v0.1.11

Perbaikan aplikasi menutup sendiri saat logo muncul pada v0.1.10. Aturan optimasi release Android yang diperlukan Tauri/Jackson dipulihkan; R8 tetap aktif.

- Tetap memakai package produksi `id.sakelar.client` dan release signing key yang sama. Bisa dipasang sebagai pembaruan v0.1.10 tanpa menghapus aplikasi atau data terlebih dahulu.
- Publikasi sekarang wajib melewati uji startup pada APK final: proses tetap hidup, halaman chat/pengaturan tampil, dan tidak ada crash startup. Laporan harus cocok dengan SHA-256 APK yang diunggah.
- Tidak ada dependency baru atau perubahan transport custom endpoint dalam perbaikan ini.

Aset unduhan selalu **SuperGPT.apk**. Ini rilis biasa/latest, bukan prerelease. Checksum tersedia di `SHA256SUMS.txt`.

Validasi: 212 tes otomatis lolos, build frontend dan Rust release berhasil, Android release/R8/lint berhasil, signature key tetap dan alignment 16 KB lolos. APK final lolos tiga kali cold start serta Home/resume di emulator Android API 32 dengan translasi ARM64; halaman chat tampil dan tidak ada crash startup. [Bukti pengujian dan screenshot](https://github.com/gabrieelibrahim/SuperGPT/blob/v0.1.11/docs/verification/android-startup-v0.1.11.md) disertakan dalam source rilis.

Pengujian emulator tidak menggantikan pengujian pada Samsung fisik; mikrofon, kamera, haptic, dan kompatibilitas provider memerlukan pengujian tersendiri.
