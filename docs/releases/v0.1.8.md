# SuperGPT 0.1.8 — Android

## Bahasa Indonesia

- Fitur AI terhubung ke chat utama: status penggunaan tool, persetujuan MCP, pertanyaan interaktif, checklist, dan sumber berupa tautan.
- Pengaturan Fitur AI dan profil MCP tersedia dari antarmuka utama; endpoint dan model tetap menggunakan pilihan pengguna.
- Gerakan tarik di akhir percakapan diperbarui dengan efek elastis, indikator mengikuti tarikan, dan pelepasan untuk membuka obrolan baru.
- Tampilan chat utama tetap memakai format Markdown, kode, tabel, matematika, dan tautan yang sudah tersedia.

Unduh APK ARM64 di bawah untuk Android 7.0 atau lebih baru. APK memakai identitas paket dan debug signing yang sama dengan build Android sebelumnya agar pembaruan tetap kompatibel. Ini adalah GitHub Release biasa; APK bukan paket distribusi Play Store.

Chat langsung ke custom endpoint tetap tersedia. Fitur Agents SDK, MCP, dan pencarian web memerlukan alamat server SuperGPT SDK HTTPS yang dikonfigurasi di **Pengaturan → Fitur AI**, serta dukungan tool dari model/provider. Server Node.js tidak dibundel dalam APK. Keberhasilan pencarian web bergantung pada layanan yang dipilih dan batas penggunaannya.

Validasi: 172 pengujian otomatis, build frontend beserta pemeriksaan urutan CSS SDK, build Android, dan pemeriksaan paket/signature/checksum. Pengujian fisik pada ponsel belum dilakukan untuk rilis ini.

## English

- AI tools now run inside the main chat, with tool progress, MCP approval, interactive questions, checklists, and source links.
- AI Features settings and MCP profiles share the user's selected endpoint and model.
- Pulling past the end of a conversation now has elastic motion, a pull-driven indicator, and release-to-start-new-chat behavior.
- The existing Markdown, code, table, math, and link rendering stays in the main conversation.

Download the ARM64 APK below for Android 7.0 or newer. It retains the previous Android package identity and debug signing for update compatibility. This is a regular GitHub Release; the APK is not a Play Store distribution package.

Direct custom-endpoint chat remains available. Agents SDK, MCP, and web search require a separately hosted HTTPS SuperGPT SDK server configured under **Settings → AI Features**, plus model/provider tool support. The Node.js server is not bundled in the APK. Web search depends on the configured service and its rate limits.

Validation: 172 automated tests, frontend build and SDK stylesheet-order check, Android build, and package/signature/checksum verification. This release has not been tested on a physical phone.
