# SuperGPT 0.1.9 — Android

- Katalog Plugin baru: 69 template, 16 kategori, pencarian, halaman Ditambahkan, detail, contoh prompt, dan alur kembali.
- 13 alamat MCP resmi sudah diisi. MCP Streamable HTTP dan pencarian Exa dapat dijalankan dari chat utama tanpa server SDK terpisah melalui model Chat Completions yang mendukung function calling. Setiap panggilan MCP meminta persetujuan.
- Timeout kustom 1 detik–60 menit untuk chat dan transkripsi endpoint, dengan pilihan detik/menit.
- Startup Android memakai satu splash sampai tampilan siap; bobot font sidebar diringankan.
- Log aplikasi, perbaikan dikte endpoint, thumbnail foto, tampilan video, dan aksi menu percakapan.

Unduh APK ARM64 untuk Android 7.0 atau lebih baru. Identitas paket dan sertifikat debug tetap sama dengan APK sebelumnya agar bisa diperbarui. Ini adalah **GitHub Release biasa, bukan prerelease**; APK memakai debug signing, bukan paket Play Store.

Template katalog tidak berarti akun sudah terhubung. Layanan tertentu memerlukan bearer token, server MCP sendiri, atau OAuth yang alur login otomatisnya belum tersedia. Fitur Responses khusus provider tetap memerlukan server SDK. Batas kuota layanan dan kapabilitas model tetap berlaku. Beberapa logo memakai simbol lokal; kesamaan visual 1:1 belum diklaim.

Validasi: 196 tes otomatis, build frontend dan guard urutan CSS SDK, build Android, serta pemeriksaan manifest/signature/alignment/checksum APK. Belum diuji pada ponsel fisik; perilaku Home, mikrofon, restart, dan startup akhir masih perlu pengujian perangkat. Tidak ada API key atau konfigurasi pribadi yang dibundel.
