# SuperGPT v0.1.10

**Masalah yang diketahui:** APK ini dapat menutup saat logo muncul akibat optimasi R8 saat inisialisasi Tauri/Jackson. Gunakan [v0.1.11](https://github.com/gabrieelibrahim/SuperGPT/releases/tag/v0.1.11) yang memperbaiki startup. File v0.1.10 di bawah tetap merupakan artefak historis yang sama.

Rilis Android ARM64 dengan **release signing key tetap**, package produksi `id.sakelar.client`, dan mode debug dimatikan. Aset unduhan selalu **SuperGPT.apk**. Ini rilis biasa/latest, bukan prerelease.

## Pemasangan pertama versi produksi

APK sebelumnya memakai package `id.sakelar.client.debug` dan debug key. Versi produksi ini dipasang sebagai aplikasi terpisah; APK lama dapat tetap disimpan. Riwayat chat, API key, endpoint, dan izin aplikasi lama tidak berpindah otomatis. Ekspor percakapan yang diperlukan dari aplikasi lama dan atur kembali endpoint pada aplikasi produksi. Jangan menghapus aplikasi lama sebelum data yang diperlukan diamankan.

Setelah versi produksi ini terpasang, pembaruan berikutnya akan mempertahankan package dan release key yang sama. Updater menolak APK dengan sertifikat atau identitas yang berbeda.

## Perubahan

- Pembaruan GitHub: pemeriksaan dan unduhan otomatis, pilihan Wi-Fi, verifikasi SHA-256/ukuran/package/versi/sertifikat, serta banner pemasangan. Android 12+ dapat mencoba pemasangan saat aplikasi tidak digunakan; izin atau konfirmasi Android tetap berlaku.
- Respons kaya: Markdown saat streaming, blok kode dengan tombol salin, tabel, rumus KaTeX dan komponen terstruktur dengan validasi keamanan. Blok yang sudah selesai dipertahankan saat teks berikutnya masuk; renderer pertama memakai skeleton.
- Getaran streaming: jawaban pendek/sedang memberi satu getaran saat selesai. Jawaban panjang dapat memberi getaran halus bertahap. Bisa dimatikan melalui Pengaturan > Umum.
- Pengurangan pekerjaan render dan penyimpanan riwayat selama streaming, dengan penyimpanan akhir tetap dipastikan.
- Build/publikasi menolak APK debug atau signing key yang berbeda. Private key dan kredensial signing tidak disertakan dalam Git/APK.
- Ekspor obrolan, library file lokal, pilihan endpoint dikte terpisah, notifikasi penyelesaian, perbaikan fokus composer/menu sesi, dan perbaikan batas unggahan gambar dari perubahan setelah v0.1.9 juga disertakan.

## Batasan dan validasi

Endpoint kustom yang didukung tetap memakai transport yang sama. Provider tetap menentukan dukungan audio, vision, MCP dan tools. Komponen terstruktur memerlukan event yang didukung; HTML/JavaScript model dan aksi widget sembarang tidak dijalankan. Tidak semua komponen ChatKit didukung.

208 tes aplikasi, build frontend dan pemeriksaan urutan CSS SDK lolos. Rust release, Android release dengan R8/lint, sertifikat signing tetap, status non-debuggable, serta alignment APK/ELF 16 KB sudah diperiksa. Tampilan rich response diuji di browser mobile; kesamaan mutlak dengan UI privat ChatGPT tidak diklaim. Pengujian di ponsel fisik, termasuk getaran, izin pemasangan, dan pembaruan otomatis antarversi produksi, masih diperlukan.
